# 팀 아마겟돈 프로젝트

 - 사용자들이 인테리어 및 생활 콘텐츠와 상품을 통합 체험하는 웹 플랫폼 개발
 - 사용자들은 자신의 공간을 공유하거나 의견을 나누며 사례를 볼 수 있음

## 프로젝트 파트
- 회원시스템
- 커뮤니티
- 인테리어 커뮤니티
- 쇼핑
- 관리자 페이지

## 기술 스택
- **백엔드** : Java 17, Spring Boot 3.5.2, Maven, MyBatis
- **프론트** : HTML5, JavaScript, CSS, jQuery, JSTL

## DBMS
- MariaDB(8.0)

## 서버
- Apache Tomcat(9.0)
- AWS EC2 Ubuntu 22.04 LTS
- AWS RDS (MariaDB)

## 버전관리
- Git, GitHub

## 테스트
- JUnit, Mockito

## 개발환경
- IntelliJ IDEA ULtimate(2024.2)
- Spring Tool Suite(STS 4.25)

## 패키징
- WAR

## 보조도구
- Postman
